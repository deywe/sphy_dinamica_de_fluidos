## 🎮 How to Use

1.  Ensure your dataset is located at `sphy_data/sphy_simulation.parquet`.
2.  Ensure your manifest is located at `sphy_data/sphy_manifest.json`.
3.  Run the auditor:
    ```bash
    python sphy_visualizer.py
    ```

The interface will display a **GREEN "VERIFIED"** status as long as the data integrity matches the SHA-256 signatures. If any bit of the data is altered, the system will trigger a **RED "CRITICAL"** alert.
